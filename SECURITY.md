# Security policy

## Report a vulnerability

Please report suspected vulnerabilities in MicAI through
[GitHub private vulnerability reporting](https://github.com/miles-chu10/MicAI/security/advisories/new).

Do not include vulnerability details in public issues or pull requests.

Include the affected version or commit, steps to reproduce the problem, and its
potential impact. Use a minimal example with synthetic data; remove credentials,
access tokens, and personal information from reports and attachments.

Use the private report for follow-up discussion and coordination before public
disclosure.
